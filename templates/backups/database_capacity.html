What are data files and transaction logs?

Data files hold P6 records and indexes. Allocated space is reserved on disk and can include reusable space; used data is the part currently occupied.

Transaction logs record database changes so SQL Server can complete or undo transactions and recover after a crash. Log space can be reused. A large allocated log file does not mean it is full: check the log usage below. Logs use disk space separately from the Express data limit.
